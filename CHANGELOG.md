# Changelog

## 1.0.0 - 2026-11-18

First public release of sandscale under the Apache-2.0 licence: sandboxes (create, run with live
output, logs, files, pause, resume, snapshot, stop, list), ports, preview links and SSH,
organization snapshots, templates and sandbox policy, webhooks with a signature verifier,
run traces and OTLP export, object storage, workspaces, build hosts, lab hosts, Agent Cloud
tasks and the account (plan, usage, regions, API keys), with typed errors for every coded API
error, a region per client and per call, and retries of safe calls only.
