# Security policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately:

- through GitHub's private vulnerability reporting on this repository (Security tab, "Report a
  vulnerability"), or
- by email to security@neuralinverse.com with the subject `[VULN]` and a short description.

Include the SDK version, what you observed, how to reproduce it and its impact. We acknowledge a
complete report within two business days and coordinate disclosure after a fix. Please give us a
reasonable time to fix an issue before you disclose it.

## Scope

This repository is the Sandscale client SDK. Issues in the Sandscale service itself (API,
console, sandboxes) go to the same address. Never include real API keys or tokens in a report;
revoke any key you pasted somewhere by mistake in the Sandscale console.

## Supported versions

The latest 1.x release receives security fixes.
